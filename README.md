# Insula Deserta: Империя

Очищенная и обновлённая версия кооперативной RPG на Сицилии.

## Запуск

```sh
npm ci
npm start
```

Для локальной разработки: `npm run dev`. Режим разработки даёт отладочные команды всем вошедшим игрокам; на общем игровом сервере используйте обычный `npm start` без `DEV=1`.

## Amvera

Конфигурация находится в `amvera.yaml`: `node server.js`, порт 3000, постоянное хранилище `/data`. В корне исходного проекта должны находиться `package.json`, `package-lock.json`, `amvera.yaml` и `server.js`.

Мир сохраняется в `rpg-world.json`, персонажи — в `rpg-chars.json`. Тестовые сохранения в архив не включены. При обновлении существующего сервера сохраняйте его постоянный каталог данных.

Главная страница: `/`. Игровой WebSocket: `/rpg`. Проверка доступности: `/health` или `/healthz`. Старая игра `/classic` удалена.

## Изменения и проверка

- `docs/CHANGES_RU.md` — все изменения этой сборки и правила новых механик.
- `docs/AUDIT_RU.md` — найденные несостыковки, баланс, предложения по оптимизации.
- `docs/VERIFICATION_RU.md` — выполненные проверки и ограничения проверки графики.
- `npm test` — проверки новых игровых правил на изолированных данных, без загрузки боевого мира.
