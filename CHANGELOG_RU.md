# Версия 0.2.0

Реализованы исправления и дополнения по запросу владельца проекта.

| Область | Изменение |
|---|---|
| Земля | Постоянная разметка купленных клеток в 3D и переключатель видимости |
| Стрельба | Высота по рельефу, пролетаемый отрезок попадания, стрелы и болты, разделение сторон |
| Армии | Общие характеристики игрока/бота, настоящая конница, явные потери и платное пополнение |
| Стратег Z | Наклонная камера, мышь, рамка выбора, несколько отрядов, курсор атаки, точки строя, карточки и команды |
| Лошади | Разгон, торможение, ограниченный поворот, снижение манёвренности на скорости |
| Вход | Пароль к коду, scrypt, секрет гостя отдельно от публичного ID, ограничение попыток, инструмент восстановления |
| Доступ | Проверки собственности и расстояния для операций с чужим грузом и ящиками |
| Цены | Положительные цены и защита от немедленного арбитража у одного продавца |
| Флот | Единый лимит активных судов, отдельные остовы, подъём/списание, продажа в гавани |
| Торговля | Гильдии в городах, обучение с рецептом и маркерами, сохранение груза маршрутов и учёт дохода |
| Баланс | Ограничение уровней набегов, учёт игроков онлайн, стоимость замены павших бойцов, первый проход цен ящиков |
| Работники | Жильё на 8 мест, места дома/виллы, назначение жильцов и штраф производства при нехватке |
| Склады | Личный городской ресурсный склад, автоматическая доставка производства, общий склад снабжения |
| Должности | Полномочия и местные бонусы всех должностей действуют в своём городе |
| Стража | Граница города, оборона, два патруля форума, возврат к арсеналу раз в 10 минут |
| Интерфейс | Отдельная строка денариев, устранение наложения на обучение, карточки в один ряд с прокруткой |
| Мессана | Новые здания по городской сетке, защита всей территории гавани, безопасное исправление ранних размещений |
| Очистка | Удалена прежняя отдельная игра, сохранены используемые RPG общие ресурсы |
| Проверки | 64 автоматические проверки и локальные браузерные сценарии |

Полноценная мораль/усталость/натиск, осады и новый алгоритм движения целого отряда не входят в эту версию. Оставшиеся вопросы, сравнительные характеристики и рекомендации — в `AUDIT_RU.md`.

При обновлении: согласованная резервная копия двух файлов данных, один серверный процесс, назначение паролей старым персонажам через `tools/reset-login.mjs`. Производственный сервер Amvera автоматически не обновлялся.
